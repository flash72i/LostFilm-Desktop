# LostFilm Desktop — план и архитектура

Неофициальный десктопный клиент LostFilm.TV на Kotlin + Compose Desktop.
Документ описывает текущее состояние приложения (v1.0.0).

> Прежняя версия этого плана содержала инвентаризацию Android-приложения и
> встроенный плеер на VLCJ (`EmbeddedMediaPlayer`). Эта информация устарела:
> встроенного плеера в приложении нет, воспроизведение идёт через внешние
> плееры. Если встретишь упоминания VLCJ/Leanback MediaPlayer в старых
> обсуждениях — это исторические заметки, а не текущая реализация.

## 1. Что делает приложение

- Вход по e-mail и паролю (капча, «запомнить пароль» через DPAPI).
- Главная: настраиваемые ряды «Новые эпизоды», «Избранные сериалы»,
  «Все сериалы», «Новые сериалы», «История просмотра», «Фильмы».
- Поиск, фильтры (жанр, год, канал, группа), календарь премьер.
- Карточки сериала и эпизода, сезоны, список эпизодов, отметки просмотра.
- Воспроизведение через внешний плеер, выбор качества, выбор плеера по умолчанию.
- Переключение зеркал, проверка доступности, авто-выбор рабочего зеркала.
- Настройки, кэш постеров, скачивание VLC из приложения.

## 2. Воспроизведение

Встроенного плеера нет — это осознанное решение. Цепочка:

1. Пользователь выбирает качество/раздачу на экране эпизода или фильма.
2. `TorrServerManager` поднимает локальный TorrServer и отдаёт поток.
3. Приложение ждёт готовности потока (`streamIsReady`); если пиров нет —
   показывает сообщение и не запускает плеер «в пустоту».
4. `PlayerRegistry` выбирает внешний плеер (VLC, PotPlayer, GOM, KMPlayer,
   пользовательские exe из `players/`), `PlaybackSources` подбирает ссылку.
5. VLC запускается с `--no-one-instance`, чтобы не мешал уже открытому VLC.
6. Если TorrServer не готов, используется резервный прямой ссылочный путь.

`VlcDownloader` скачивает актуальный VLC с `get.videolan.org` и регистрирует
его как плеер. Плеер можно сменить в настройках.

## 3. Стек

- Kotlin 2.1.21, Compose Desktop 1.8.2, Material 3, JDK 21.
- OkHttp 4.12, Jsoup 1.18.3, org.json.
- Сборка — Gradle wrapper, без установленного Gradle.

## 4. Архитектура

```
core\      AppPaths, SettingsStore, CredentialsStore (DPAPI),
           PlayerRegistry, AppInfo
data\      LostFilmApi, TorrServerManager, VlcDownloader, ImageCache,
           PlaybackSources, Models, net\Http, net\PersistentCookieJar
ui\        App, AppModel (единое состояние), экраны, диалоги, тема
platform\  DesktopUtils, VoiceInput
```

- Состояние — единый `AppModel` с Compose `mutableStateOf`.
- Сеть — OkHttp + Jsoup; cookie jar сохраняет сессию между запусками.
- Экраны: Login, Home, Search, Filters, Calendar, Details, EpisodeDetails,
  Settings, About.
- Ряды главной настраиваются в `SettingsStore` (`homeRows`).
- «Новые эпизоды» подгружаются постранично (по 15) при прокрутке.

## 5. Данные и хранение

- Портативный режим: маркер `portable.marker` рядом с exe, данные в `data\`.
- Обычный режим: `%APPDATA%\LostFilmDesktop`.
- `settings.properties` — настройки, `cookies.tsv` — cookies.
- Пароль хранится в зашифрованном виде (DPAPI) и не пишется открытым текстом.
- `ImageCache` кэширует постеры на диск с ограничением размера.
- Иконки плееров — `player-icons\` в каталоге данных.

## 6. Сеть, авторизация, зеркала

- Зеркало по умолчанию — `www.lostfilm.download`; список зеркал хранится в
  настройках, можно добавлять и удалять.
- `autoMirror` перебирает зеркала при ошибках; сессия проверяется перед
  загрузкой каталога.
- Вход: `POST /ajaxik.users.php` с капчей; при смене зеркала сессия может
  слетать — приложение предложит войти заново.
- Каталог: `POST /ajaxik.php` постранично, серии и фильмы грузятся параллельно.
- Ленты новинок: `GET /new/page_N/type_0`, эпизоды — `/v_search.php`.

## 7. Установщик

- Отдельный проект `installer\src` — C# 5, WinForms, интерфейс рисуется вручную
  через GDI+ (без Inno Setup/NSIS).
- Один `Setup.exe`: в конец дописан ZIP payload и хвост
  `ADBWIFISETUP0001` + int64 длина.
- По умолчанию ставится в `%LOCALAPPDATA%\Programs\LostFilmDesktop` без прав
  администратора, запись в «Приложения» — в HKCU.
- `Uninstall.exe` кладётся в установленную папку и чистит файлы, ярлыки и реестр;
  данные пользователя не удаляет.
- Вариант для всех пользователей (`Program Files`, HKLM) — сборка с `-Admin`.

## 8. Тесты

`src\test` — 9 тестов: DPAPI, выбор источников воспроизведения, санитайз
списка плееров, загрузчик VLC. Запуск: `.\gradlew.bat test`.

## 9. Ограничения и планы

Не реализовано:

- скачивание серий на диск;
- уведомления о новых эпизодах;
- синхронизация истории просмотра с сайтом;
- автообновление приложения;
- сборки под Linux/macOS;
- кэш каталога на диске (первый полный каталог грузится с сети, карточки
  первых страниц появляются сразу).

Известные проблемы:

- сессия может слетать при смене зеркала;
- воспроизведение зависит от TorrServer и наличия пиров;
- при отсутствии пиров плеер ждёт данных, а не стартует мгновенно.

Ближайшие кандидаты: кэш каталога, уведомления, автообновление, аккуратная
синхронизация отметок просмотра.
